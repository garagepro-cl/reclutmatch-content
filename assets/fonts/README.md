# Fuentes tipográficas

En Windows el sistema usa Segoe UI automáticamente — no necesitas hacer nada.

Si mueves la app a un VPS Linux, o quieres otra tipografía de marca, deja aquí:

- `regular.ttf` — peso normal (cuerpo de texto)
- `bold.ttf` — negrita (subtítulos)
- `black.ttf` — extra negrita (titulares)

Sugerencias gratuitas que combinan con la marca: Inter, Archivo, Montserrat
(descarga los .ttf desde https://fonts.google.com).
