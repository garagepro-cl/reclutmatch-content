# Música para los videos

Deja aquí archivos `.mp3` (o `.m4a`/`.wav`) **libres de derechos** y el sistema
elegirá uno al azar para cada video.

- `assets/music/*.mp3` → disponible para todos los negocios
- `assets/music/garage-pro/*.mp3` → solo para Garage Pro
- `assets/music/euro-pro-parts/*.mp3` → solo para Euro Pro Parts

Si no hay música, los videos salen sin audio (Instagram y YouTube lo aceptan,
y de hecho mucha gente ve Reels en silencio).

Fuentes de música libre de derechos recomendadas:
- https://pixabay.com/music/ (gratis, sin atribución)
- https://www.youtube.com/audiolibrary (biblioteca de audio de YouTube Studio)
- https://incompetech.com (Kevin MacLeod, requiere atribución)

⚠️ No uses canciones comerciales: Instagram/YouTube silencian o bajan el video.
